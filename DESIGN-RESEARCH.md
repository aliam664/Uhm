# Design research applied — August 2026

This build uses the following review principles, applied as product decisions rather than copied visual trends.

| Finding | Application in UHM |
|---|---|
| A page needs clear scale, hierarchy, balance, contrast and Gestalt grouping. | The primary download action remains the only high-contrast primary CTA; the first install step is visually promoted as the start of the guide sequence; cards use consistent boundaries and spacing to group related tasks. |
| Extra visual information competes with task-critical information. | Decorative diagonal treatment in the hero was reduced. The layout keeps real gameplay, the downloadable pack, and the next installation action above decoration. |
| Comfortable text measure and spacing support scanning. | Supporting copy is constrained to readable line lengths instead of stretching across content cards. |
| Motion should be brief, purposeful, performant and optional. | UI transitions use shared timing tokens, reveal uses transform/opacity, the readiness meter uses transform scale rather than width animation, reduced-motion support remains on, and hero video is paused on compact screens. |

## Sources reviewed

- Nielsen Norman Group, [5 Principles of Visual Design in UX](https://www.nngroup.com/articles/principles-visual-design/): scale, hierarchy, balance, contrast and Gestalt.
- Nielsen Norman Group, [Aesthetic and Minimalist Design](https://www.nngroup.com/articles/aesthetic-minimalist-design/): remove noise that competes with essential tasks.
- Smashing Magazine, [10 Principles of Readability and Web Typography](https://www.smashingmagazine.com/2009/03/10-principles-for-readable-web-typography/) and [Balancing Line Length and Font Size](https://www.smashingmagazine.com/2014/09/balancing-line-length-font-size-responsive-web-design/): hierarchy, contrast, measure and spacing.
- NN/G, [Executing UX Animations](https://www.nngroup.com/articles/animation-duration/): use restrained motion with a purpose and honor accessibility needs.
