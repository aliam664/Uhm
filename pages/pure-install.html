آموزش نصب ماد Pure

Pure پیش‌نیاز اصلی پک گرافیکی UHM است. اول این بخش را کامل کن، بعد برو سراغ CSP و بقیه.

ویدیوی آموزشی نصب Pure

ویدیو آموزشی Pure Ali369 · UHM دانلود / باز کردن ویدیو
نکته اگر ویدیو اینجا پخش نشد، روی «دانلود / باز کردن ویدیو» بزن. بهتر است هم‌زمان با ویدیو مراحل پایین را هم بخوانی.
  1. 1

    پیش‌نیازها

    • Content Manager نصب باشد.
    • Custom Shaders Patch (CSP) نصب و ترجیحاً به آخرین نسخه آپدیت باشد.
    • بازی Assetto Corsa حداقل یک‌بار از طریق CM اجرا شده باشد.
  2. 2

    دانلود Pure

    آخرین نسخه Pure را از منبع معتبر (همان مسیری که در ویدیو نشان داده می‌شود) دانلود کن.

    ⚠ مهم نسخه قدیمی Pure با پک UHM ممکن است ناسازگار باشد. همیشه آخرین نسخه را نصب کن.
  3. 3

    نصب داخل Content Manager

    فایل Pure را روی پنجره Content Manager بکش و رها کن (Drag & Drop)، یا از Install نصب کن.

    اگر گزینه Replace آمد، آن را تأیید کن تا نسخه قبلی جایگزین شود.

    در پایان روی Install / OK بزن و صبر کن تا نصب تمام شود.

  4. 4

    فعال‌سازی و تست

    بازی را یک‌بار اجرا کن و مطمئن شو پنل Pure / Pure Config در نوار کناری دیده می‌شود.

    اگر Pure بالا نیامد، CSP و مسیر نصب را دوباره از روی ویدیو چک کن.

  5. 5

    بعد از نصب Pure

    حالا می‌توانی پک UHM را ادامه بدهی:

    بعدی: CSP Setting بعداً: Pure Config پک

    توجه: «نصب Pure» با «Pure Config پک UHM» فرق دارد. اول خود ماد Pure را نصب کن، بعد کانفیگ پک را اعمال کن.
