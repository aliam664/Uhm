Pure Config

این مرحله بعد از نصب خودِ Pure انجام می‌شود؛ Pure Config و Pure Install یکی نیستند.

Step by step

مسیر انجام کار

\SteamLibrary\steamapps\common\assettocorsa\extension\config-ext\Pure
  1. فایل Pure Config را در مسیر بالا کپی کن.
  2. بازی را اجرا کن و نوار کناری سمت چپ را باز کن.
  3. پنل Pure Config را انتخاب کن و IMPORT را بزن.
  4. کانفیگ UHM را انتخاب کن و در پایان SAVE را بزن.
