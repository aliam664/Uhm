Troubleshooting

If something goes wrong.

Check the setup in order instead of changing files at random.

Crash or black screen

Check Pure and CSP first, then test a lighter preset.

Broken colours or graphics

Recheck PP Filter, Pure Config and the selected preset.

FPS drop

Start with Medium or Low. This site does not publish FPS without a real benchmark.

Preset will not load

Match the file path to its guide and restart Content Manager.

RECOVERY PATH
  1. Restore your backup.
  2. Disable the UHM preset.
  3. Check CSP and Pure.
  4. Test a Low preset.
  5. Return to defaults and apply the steps again.

FAQ

Common questions

What should be installed first?

Content Manager, CSP, Pure and Light Patch. Then apply the pack presets.

Which preset suits an RX 580?

Medium is the recommended starting point. Try Low if FPS is not stable.

My graphics look broken or the game crashes.

Update Pure and Light Patch, check the selected preset, and start from a lighter configuration.
