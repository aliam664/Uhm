Neck FX

Install and activate Cockpit Neck FX from the official link.

Step by step

Installation path

  1. Open the official Neck FX link.
  2. Select Open in Content Manager.
  3. Once Content Manager opens, select Save & Apply.
  4. In Settings → Custom Shaders Patch → Cockpit (Neck FX), make sure Active is enabled.
