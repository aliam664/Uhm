Install Pure

Pure is the foundation of this pack. Install it before importing the UHM Pure Config.

Step by step

Installation path

  1. Watch the Pure tutorial below and install the latest Pure build from a trusted source.
  2. Install it through Content Manager using Drag & Drop or Install. Choose Replace if prompted.
  3. Launch the game once and confirm that the Pure panel is available.
  4. Continue with CSP Settings, then import the UHM Pure Config.
