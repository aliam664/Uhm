## قانون طلایی

1. هر وقت عکس/ویدیو/متن عوض شد → **اول اینجا آپدیت کن**، بعد کد.  
2. اسم فایل‌های مدیا را **عوض نکن** مگر همزمان این پوشه را هم آپدیت کنی.  
3. بخش‌هایی که عکس ندارند را با بج «با عکس» علامت نزن.  
4. «نصب Pure» ≠ «Pure Config پک» — دو بخش جدا هستند.
