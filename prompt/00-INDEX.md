# 00 — نقشه سریع پروژه

## محصول چیست؟

سایت **استاتیک** راهنمای نصب پک گرافیکی **UHM** برای **Assetto Corsa**.

کاربر باید بتواند:
1. پک را دانلود کند  
2. ویدیوی نمایش گرافیک را ببیند  
3. مرحله‌به‌مرحله هر بخش را نصب کند  
4. اسکرین‌شات‌ها / ویدیوی آموزشی را ببیند  
5. به پشتیبانی تلگرام برسد  

---

## استک فعلی

| مورد | مقدار |
|------|--------|
| نوع | Static HTML / CSS / JS |
| فریم‌ورک | ندارد (بدون React/Next) |
| زبان UI | فارسی پیش‌فرض + سوییچ EN (متن EN ناقص/placeholder) |
| تم | Dark / Light |
| فونت | Vazirmatn (FA) + Outfit (EN/برند) |
| هاست مدیا | لوکال در `assets/` + یک ویدیو CDN برای Pure |

---

## درخت مهم پروژه (وضعیت فعلی — آرشیو)

```
Uhm/
├── README.md                 # مرجع کامل (همه‌چیز سر دست)
├── content/                  # متن خام txt راهنماها (۸ فایل)
├── assets/
│   ├── logo.png
│   ├── media/                 # ویدیوها (showcase + آموزش Pure)
│   ├── download/              # فایل پک (rar)
│   └── guides/                # عکس‌های هر بخش (شماره‌دار)
└── prompt/                    # ← این آرشیو طراحی ★
```

> ⚠️ فایل‌های کد (`index.html`، `css/`، `js/`، `pages/`) از ریپو حذف شده‌اند.
> برای ساخت دوباره، مشخصات فنی هدف را در `05-settings/TECH-STACK.md` و اسامی فایل‌های پیشنهادی را در `02-structure/PAGES.md` ببین.
