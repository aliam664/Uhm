## مراحل متنی پیشنهادی

1. **پیش‌نیاز:** CM · CSP · یک‌بار اجرای بازی  
2. **دانلود Pure** از منبع معتبر (طبق ویدیو) — نسخه آخر  
3. **نصب در Content Manager** با Drag & Drop / Install — Replace اگر آمد  
4. **تست:** اجرای بازی · دیدن پنل Pure  
5. **بعدی:** برو CSP Setting · بعداً Pure Config پک
