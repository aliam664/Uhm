# 03 — نمای کلی محتوا

## نسخه‌های گرافیکی پک

| نسخه | توضیح FA | پیشنهاد |
|------|----------|---------|
| Low End PC | سیستم ضعیف — بیشترین FPS | — |
| Low | کیفیت پایین، روان | — |
| **Medium** | تعادل کیفیت / FPS | **پیشنهادی برای RX 580** |
| High | کیفیت بالا | سیستم نسبتاً قوی |
| Ultra | حداکثر گرافیک | سیستم قدرتمند |

## پیش‌نیازهای کلی (قبل از پک)

1. Content Manager  
2. Custom Shaders Patch (CSP) — آخرین نسخه  
3. **Pure** — آخرین نسخه (**بخش ۱ سایت**)  
4. Light Patch — آخرین نسخه  
5. بکاپ از فایل‌های بازی  

## هشدارهای قرمز (همیشه نشان بده)

- بدون Pure یا Light Patch (یا قدیمی) → گرافیک خراب / اجرا نشدن  
- نسخه نامتناسب → افت FPS / لگ / کرش  
- اگر بلد نیستی نصب کنی → اول آموزش کامل  
- مسئولیت با کاربر  
- بکاپ قبل از نصب  

## متن خام اصلی

فایل‌های txt اولیه در:

- `content/`  ← تنها منبع متن خام (۸ فایل)

> نسخه‌های تکراری ریشه حذف شدند تا همه در یک پوشه مرتب باشد.

جزئیات هر بخش → فایل‌های جدا در همین پوشه `03-content/`.
