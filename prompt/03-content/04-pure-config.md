## مراحل

### ۱) کپی فایل Config
```text
\SteamLibrary\steamapps\common\assettocorsa\extension\config-ext\Pure
```

اگر پوشه `Pure` نبود بساز. خود Pure باید از قبل نصب باشد.

### ۲) داخل بازی
1. اجرای بازی  
2. نوار کناری چپ → **Pure Config**  
3. **IMPORT**  
4. انتخاب `Uhm Private Config.ini`  
5. **SAVE**
