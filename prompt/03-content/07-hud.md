## مراحل

1. فایل HUD را داخل **Content Manager** بینداز (Drag & Drop)  
2. مسیر:
   ```
   SETTINGS → Assetto Corsa → Python Apps
   ```
3. تیک **Forza Horizon 4 HUD** را فعال کن  
4. داخل بازی از نوار سمت راست HUD را فعال کن  

## کپشن عکس

- ASSETTO CORSA + PYTHON APPS  
- تیک Forza Horizon 4 HUD  
- فلش SETTINGS بالا راست
