# 04 — کپشن تک‌تک عکس‌های آموزش

## CSP — `01-csp/csp-setting.jpg`

- **عنوان:** انتخاب پریست CSP  
- **توضیح:** SETTINGS (بالا راست) → CUSTOM SHADERS PATCH → General Settings → پایین راست لیست `Uhm Private Csp (*)`  
- **علامت‌های داخل عکس:** دایره روی تب CSP · خط زیر General Settings · براکت قرمز روی preset  

## Pure Config — `03-pure-config/01-click-import.jpg`

- **عنوان:** دکمه IMPORT  
- **توضیح:** پنجره Pure Config · پایین راست IMPORT (دایره قرمز)  

## Pure Config — `03-pure-config/02-select-uhm-config.jpg`

- **عنوان:** انتخاب Uhm Private Config.ini  
- **توضیح:** مسیر `...\extension\config-ext\Pure` · فایل `Uhm Private Config.ini` هایلایت قرمز  

## Video — `04-video/video-setting.jpg`

- **عنوان:** انتخاب پریست ویدیو  
- **توضیح:** SETTINGS → ASSETTO CORSA → VIDEO → presetهای `Uhm Private video (*)`
