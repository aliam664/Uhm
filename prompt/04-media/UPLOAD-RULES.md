# 04 — قوانین آپلود مدیا

## کجا آپلود کنیم؟

| نوع | پوشه |
|-----|------|
| لوگوی جدید | `assets/logo.png` (جایگزین) |
| ویدیو showcase | `assets/media/uhm-showcase.mp4` |
| ویدیو Pure | `assets/media/pure-install-tutorial.mp4` یا فقط CDN |
| پک | `assets/download/uhm-graphics-pack.rar` |
| عکس آموزش | `assets/guides/<پوشه-بخش>/` |
| گالری | `assets/guides/09-graphics-test/` |

## نام‌گذاری

- انگلیسی کوچک + خط تیره ترجیح دارد  
- فارسی در اسم فایل اوکی است اگر کپشن باشد، ولی بهتر است کپشن در `IMAGE-CAPTIONS.md` بیاید  
- بعد از آپلود:  
  1. جدول `MEDIA-MAP.md` را آپدیت کن  
  2. اگر بخش قبلاً عکس نداشت → بج «با عکس» را در UI روشن کن  
  3. صفحه مربوط + لندینگ را وصل کن  

## محدودیت‌ها

- گیت‌هاب برای فایل خیلی بزرگ مناسب نیست (ویدیو/پک حجیم → CDN یا Drive)  
- اگر لینک خارجی شد، هم در UI و هم در این پوشه `prompt` ثبت شود  

## کارهایی که نکن

- عکس را کنار پوشه‌های `01-csp` و … نگذار (داخل همان پوشه بگذار)  
- اسم `uhm-showcase.mp4` را بی‌هماهنگی با کد عوض نکن  
- zip و rar را قاطی نکن (الان RAR است)
